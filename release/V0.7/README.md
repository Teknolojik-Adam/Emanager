# Emanager Linux V0.7

The original `Emanager-Linux-x64V0.7.tar.gz` archive is stored as 15 numbered binary parts due to connector upload-size constraints. To reconstruct it after cloning/downloading **all parts**:

```bash
cd release/V0.7
bash assemble.sh
```

Expected SHA-256 of the resulting archive:

`a491f63b46ee606687da71b13b94ffae87e9a688bd636f52f4e44f6f755dcca5`

Source code is available in `src/` on the `linux` branch; tests in `tests/`.
